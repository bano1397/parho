# Parho demo video script (target 2:50, max 3:00, English narration, upload to YouTube Public with English subtitles)

Everything is recorded on the Mac: the web app in Chrome, the iPhone app in the iPhone 17 simulator, the Android app in the Parho_Pixel emulator (its camera is the Mac webcam).
Record each scene separately with **Cmd + Shift + 5 → Record Selected Portion** (only the app window, no other tabs or notifications). Shehar Bano adds the voice-over afterwards.
Use the **fake samples**, or real papers with the name, CNIC, address and account number covered. Each AI step takes 15–30 s: cut the waits in editing and show a small "sped up" label.

| Time | Screen | Narration |
|---|---|---|
| 0:00–0:12 | Ammi's or Abbu's **hands only** holding an electricity bill (private parts covered) | "In Pakistan, millions of people get bills, disconnection notices and medicine boxes they can't easily read. To get help, they hand the paper to someone else, with their CNIC, address and account number on it." |
| 0:12–0:22 | Web app in Chrome: title, "On-device AI ready" chip; tap **English**, then **اردو** | "Parho reads the paper on your own device, removes your private details, and explains it in simple Urdu, or English with one tap. It runs on the web, iPhone and Android." |
| 0:22–0:55 | Web: tap **Gas notice** → "Read on this device" fields with 🔒 → scroll to **What the cloud will see** (point at `[NAME]`, `[CNIC]`, byte count) | "On the web, Gemini Nano runs inside Chrome through Firebase AI Logic's on-device mode, so the photo never leaves this laptop. Before anything goes online you see exactly what will be sent: about one kilobyte of text, no photo, every name and number replaced. A Safety Net in code blocks the request if a CNIC or phone number is still there." |
| 0:55–1:15 | Web: **بھیجیں اور سمجھائیں** → Urdu answer → 🔊 | "Only the explanation uses cloud Gemini, because the on-device model doesn't write Urdu. Pay 6,780 rupees by 30 November, or the gas will be cut off." |
| 1:15–1:45 | **iPhone simulator**: open Parho → tap **Electricity bill** → timeline shows "Apple Vision (this phone)" and "Apple on-device model" → fields → Urdu answer with the 78% note | "On iPhone, Apple's Vision reads the text and Apple's on-device model organises it, all on the phone. The same privacy code runs before Gemini explains it, and Parho notices this month's units are 78 percent above the average and suggests checking the meter." |
| 1:45–2:15 | **Android emulator**: tap **تصویر لیں** → the Mac webcam takes a photo of a covered real bill (or tap a sample) → "send redacted text?" card with [NAME], [CNIC], [ACCOUNT] → Send → answer | "On Android, ML Kit reads the paper on the phone, and Gemini Nano organises it on phones that have it. On this phone there's no Nano, so Parho hides every private detail first and asks before sending anything." |
| 2:15–2:30 | Any platform: **Medicine box** → only name and strength shown → answer ends with the pharmacist line | "For medicine, Parho never invents a dose. It repeats only what's printed and always says: ask a doctor or pharmacist." |
| 2:30–2:50 | Text on screen: "Web · iPhone · Android" / "8 real documents · 21 of 22 key facts (95%) · 0 private details sent" (web, 20 Nov) / "Privacy tests on every platform", then the GitHub repo | "We tested the web app on eight real Pakistani documents: 21 of 22 key facts correct, and zero private details reached the cloud. The same privacy rules and tests run on iPhone and Android. Parho: read any paper, privately." |

Numbers: 21/22 key facts and 0 leaks are from the real 20 Nov live re-test of the web app (eval/private). Never add a number that isn't backed by a test.
